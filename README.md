## Running
Each node is a standalone Maven project built on **JDK 25**.

```bash
cd 01-java-core
mvn compile
```

## What's inside
- **01-java-core**: `MyHashMap`, a hand-built hash map implementation for studying bucket hashing, resizing, and collisions.
